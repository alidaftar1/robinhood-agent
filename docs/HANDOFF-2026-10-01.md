## Deployed and live

The **TTM quality gate**. The screen previously ran on 12–15-month-old fundamentals every Q1
(on 2 Jan 2022 it was still using FY2020, so it excluded energy on COVID-year losses in the month
before energy became that year's only winning sector). It now uses trailing-twelve-months, and names
whose quality cannot be established are withheld from BUYING but RETAINED if already held — so a data
gap can no longer read as "fell off the shortlist" and authorise a sell.

Measured basis over 28 survivorship-free years: **+2.36 CAGR, +0.07 Sharpe**. The actual argument was
first-principles (screening on year-old numbers is wrong regardless); the backtest corroborates.

Eligible set moved 205 → 200. SWKS dropped (it was eligible on an overstated 6.06% ROA); ADI and UAL
returned; FDX/MDT/ED went from effectively-zero ROA to sane. Holdings at deploy time intersected
neither the withheld nor the newly-ineligible set, so no forced sell.

It took **five review rounds**; each one found a defect introduced by the previous fix. See
`feedback-review-gate` in memory for the pattern and the specific lesson about testing call sites
rather than predicates.

## PICK UP HERE — the sector bias is only PARTIALLY fixed

`4b31cc1` is committed but **not pushed and not deployed**, deliberately.

**The problem.** The withheld set is sector-shaped: XLE 26%, XLB 25%, XLU 24%, XLRE 23% against
XLK 4% / XLV 4% / XLI 3%. Cause: `conceptFacts` asked only for `us-gaap:NetIncomeLoss`, and many
utilities, REITs, materials and energy filers tag `ProfitLoss` instead.

**Why the obvious fix is worse than the bug — do not undo this.** `NetIncomeLoss` is attributable to
the PARENT; `ProfitLoss` INCLUDES noncontrolling interests. Measured live: FCX's NCI is **46.9%** of
its ProfitLoss, SPG's **13.7%**, AMT 3.8%, AEP 3.1%. A drop-in substitution would nearly double
Freeport and inflate exactly the sectors the bias already disadvantages — fail-open, in the worst
place. So `adjustForNci` derives `parent = ProfitLoss − NCI` instead. NCI can be negative (DOW −7.3%),
where subtracting correctly raises parent income.

**What works:** V (roa 21.98%) and SPG (11.64%) now recover with sane figures. 399 → 401 scored.

**What does NOT, and is the next task:** FCX, AEP, AMT, EXC, WEC, DOW, XOM are still withheld and the
per-sector rates are essentially unchanged. Not yet traced. Start by checking, for one of them:
1. Is its `Assets` instant present? (`recoverWithheld` only considers names where it is.)
2. Does `conceptFacts(cik, "ProfitLoss")` return facts, and does `adjustForNci` return null or a list?
3. If a list, what does `ttmFromFacts` do with it — rejected on `MAX_WINDOW_AGE_DAYS` (400), on the
   `FINANCIAL_STATEMENT_FORMS` allowlist, or on contiguity?

The V bug was instructive: my first rule withheld the whole FILER on any unsizable period, which
dropped Visa over one 2008-era period, and I had written a test asserting that behaviour. Live data
caught it, not the test. Expect the remaining names to fail for a similarly specific reason.

## Strategy findings from this session (measurement, not code)

`docs/findings-bear-market-risk.md` has the full version. The three that should change decisions:

1. **The stops never de-risk — they churn.** 0–2% of days in cash across every historical bear; 135
   stop-outs through the GFC while 98% invested. A stop fires, the next weekly rebalance redeploys.
   The stop is a NAME-level control and there is no PORTFOLIO-level one. Four candidate levers are
   written up in the conversation; the cheapest first test is `stopLossPct: null`, which already
   exists as a flag — the stops may be NET NEGATIVE in a grind rather than merely useless.
2. **Full cycle 1999–2026: CAGR 11.34% vs SPY 8.68%, but Sharpe 0.52 vs 0.53.** The excess return is
   bought entirely with risk, and at IR 0.21 (t≈1.1) it is not statistically established even over 28
   years. Worst drawdown −75.7% over nearly six years (2006-01→2011-10).
3. **Momentum loses 1.6–1.9× the market in long grinds and WINS in fast V-crashes** (COVID: +26.7% vs
   +17.3%, shallower drawdown). A de-risking rule would cost you the one regime where there is an
   edge, so that trade must be judged on all four windows AND the full cycle.

**The original question — why the main book trails SPY — is still unanswered**, and one month cannot
answer it: daily active vol is 0.85%, so the ±1σ band over 29 days is ±4.59% and the −8.35% active
return is −1.8σ, t = −1.87. The test that WOULD answer it is picked-vs-passed-over (do the names the
model selects beat the ones it skips), still blocked on feature-capture depth — capture began
2026-09-29, so it holds about three days and needs weeks.
